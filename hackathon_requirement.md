## 1. Purpose

Binance launched Agent OS on 20 August 2026 as a developer platform that connects AI agents to Binance trading, market data, wallets, payments, and on-chain tools.

The Mini Hackathon is a short sprint to:

- get builders using Agent OS immediately
- produce working AI-agent workflows (Track A)
- drive live MCP connections and real trades inside isolated Agentic sub-accounts (Track B)

Tagline from Binance: *We built Agent OS. You build what's next.*

## 3. Tracks and prizes

Total pool: **$60,000 USDC**.

### Track A — Build an AI agent with Agent OS  
**Pool:** $20,000 USDC

| Place | Prize |
|---|---|
| 1st | 2,000 USDC |
| 2nd | 1,500 USDC |
| 3rd | 1,000 USDC |
| Next 50 winners | 300 USDC each |

That is 53 paid Track A winners (3 podium + 50).  
$2,000 + $1,500 + $1,000 + (50 × $300) = $19,500, rounded to the stated $20K pool.

Track A is a judged / selected-winner track. Official graphics describe these agent workflow modules:

- **Data & Analysis** — reports, market analysis, portfolio insights
- **Trading Workflows** — signals, strategies, automated actions
- **Payment Workflows** — agent-to-agent, automated payments
- **Onchain Workflows** — staking, DeFi, on-chain actions

### Track B — Connect your MCP and trade  
**Pool:** $40,000 USDC

| Rule | Prize |
|---|---|
| First 10,000 eligible users who complete the required trading tasks | 4 USDC each |

$10,000 × $4 = $40,000.

Track B is a completion / first-N eligibility track, not a judged design contest.

Official task list for connecting an agent to **Binance MCP**:

1. **Spot trade**
2. **Futures trade**
3. **Margins or Convert trade**

Complete the listed tasks through an agent connected to Binance MCP. Eligibility is determined by Binance after survey + account checks.

You may enter one or both tracks if you satisfy each track’s requirements. Track A still requires a public submission artifact; Track B is primarily a completed MCP trading workflow plus survey.
